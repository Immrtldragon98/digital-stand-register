# Accepted product requirements

4–5 concurrent users; Cast House three lines, expandable. Public viewing, authenticated new entries, admin-only corrections/backdating. Actual recorded mill runtime determines stand and component life; monthly 12-hour PM is a plan, never assumed actual downtime. Missing historical runtime remains unknown. All component types support asset identities; reuse retains measured life and unknown baselines. New parts deduct verified stand-preparation stock atomically once on finalization. Free hosting only; no uptime/perpetual free guarantee. Offline public shell and account-scoped drafts are allowed; no silent offline writes.

Engineering handovers and release approval live in docs/handoffs. Review branch checkpoints preserve work between sessions; only approved tested state is published to main.
